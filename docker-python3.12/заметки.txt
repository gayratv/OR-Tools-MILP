  --header Metadata-Flavor:Google \

  jq -r .a

Получение IAM-токена для сервисного аккаунта
https://yandex.cloud/ru/docs/iam/operations/iam-token/create-for-sa

Аутентифицируйтесь от имени сервисного аккаунта с помощью авторизованного ключа
https://yandex.cloud/ru/docs/cli/operations/authentication/service-account

yc iam key create \
  --service-account-name sc-scheduller-srv-acc \
  --output key.json \
  --folder-id b1gbgjv35qvro3lmgaci

yc config profile create default
yc config set service-account-key key.json

yc config set folder-id b1gbgjv35qvro3lmgaci

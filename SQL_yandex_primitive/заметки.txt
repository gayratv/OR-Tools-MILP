Происходит следующее:
1. Архивация контекста: Утилита yc не просто отправляет один файл docker-compose.yml. Она определяет директорию, в которой находится этот файл, и архивирует всё её содержимое. Этот архив называется "контекстом сборки" (build context).
2. Отправка в облако: Этот архив (со всеми вашими файлами: Dockerfile, entrypoint.sh, make-mysql-certs-full.sh и, что самое важное, .env) отправляется в Yandex Cloud.
3. Запуск на ВМ: На создаваемой виртуальной машине Yandex Cloud распаковывает этот архив и запускает docker-compose.
4. Использование .env: docker-compose на ВМ видит директиву env_file: [.env] в вашем docker-compose.yml, находит рядом файл .env (который приехал в том же архиве) и использует его для установки переменных окружения в запускаемом контейнере.
Таким образом, .env файл передается неявно, как часть общего архива с файлами проекта.
